## 排查：报价页部分字段「填了数字价格不动」（只诊断，未改代码）
吴老师要求先查清再决定是否改。已完整定位，结论如下（**尚未修改任何计算逻辑**）：

### 根因（他遇到的问题）
选材料牌号后，前端会用材料库的值**强制覆盖**用户输入：
- `ConfiguredQuote.tsx` 第 398-399 行：`pp[injectionVars.lossVar] = mat.lossRate`
- 同理第 375-376 行覆盖钢材的 `lossVar`，第 373/397 行覆盖 `priceVar`，第 374 行覆盖 `densityVar`
→ 所以「原料损耗率」「钢材单价/密度/损耗率」一旦选了牌号就失效，**但输入框仍可编辑**（最误导的地方）。

### 生产实测（对照实验，admin@mqs.local / 注塑模具）
| 操作 | 含税总价 |
|---|---|
| 基线 | 87,691 |
| 未选材料时把原料损耗率 0.05→0.5 | **93,720（生效）** |
| 选定材料 ABS 后 | 87,691（被材料库 5% 覆盖） |
| 已选材料时把损耗率 0.5→0.9 | **87,691（不生效）** ← 吴老师的问题 |
| 改机台时薪 130→300 | **92,104（生效）** |

### 其他发现（配置层面空转参数）
用新增的诊断脚本 `apps/api/scripts/check-config-refs.mjs` 扫描他公司 4 套模具类型：
- 注塑：0 个空转（问题只在材料覆盖）
- 压铸：**投影面积、平均壁厚、压铸机吨位、模具寿命** 4 个完全没用；`原料损耗率` 是残留（实际用 `合金损耗率`）
- 双色：`原料损耗率` 残留（实际用 `硬胶损耗率`/`软胶损耗率`）
- 橡胶：**硫化机吨位** 没用；`原料损耗率` 残留（实际用 `橡胶损耗率`）
- 另：`注塑数量/压铸数量/成型数量/硫化数量` 属"数量类"，费用项不引用但引擎按名注入，属间接生效，不要删。

## 已实施：纳入开关 + B档损耗率可覆盖 + 价格字段只读 + Excel 干净化
吴老师选了 B 档，并要求：每栏加「纳入/不纳入计算」开关（客户信息除外、数量除外）；金额为 0 的行不出现在 Excel。

### 改动（commit `8c5d88c`）
1. **纳入/不纳入开关**（`ConfiguredQuote.tsx`）
   - 公共参数 / 模具参数 / 手填金额项 / 注塑参数 每栏右上角一个小 pill（默认绿色「纳入」，点击变灰色「不纳入」）；客户信息与「数量」不加。
   - 状态：`commonOff` + `MoldState.off` / `PartState.off`（键 = 参数名或手填项名）。
   - 语义：**不纳入 = 该值按 0 参与算价**（值仍留在页面上、输入框灰显不可编辑）。不删变量，所以不会触发"未定义变量"报错。
   - 手填项不纳入 → 不放进 `manualAmounts` → 引擎保持 manual、值 0。
2. **B 档：损耗率可覆盖**
   - 新增 `pickMoldSteel` / `pickPartMaterial`：选牌号时把材料库损耗率当**默认值带进输入框**；
   - `calcInput` 里删掉了原来强制覆盖 `lossVar` 的两处（原 375-376 / 398-399 行）→ 用户改过就以用户为准。
   - 价格与密度仍由材料库决定（价格模式 B 不变）。
3. **价格坑填上**
   - `readonlyField()`：材料驱动的价格/密度参数改只读展示 + 标注「材料库带入」。
   - `materialDriven(name, includeLoss)`：`locked`（相关模具/注塑件全都选了牌号 → 只读）/ `partial`（部分选了 → 可编辑 + 提示"只对没选牌号的生效"）。
     `includeLoss` 只在**公共参数**区块传 true —— 配置把损耗率放公共参数时，每套模具/每个注塑件都会各自覆盖它，那个公共值就是摆设，必须标只读。
   - 注塑件未选牌号时补一行只读说明"按配置中心同步价 ¥X/kg（此处只读，要改价格去材料库）"。
4. **Excel 隐藏 0 行**（`excel.ts`）
   - `visibleLines(lines)` = 过滤 `Number(l.value) !== 0`；主表与明细表都套用；分组表头按过滤后长度判断。
   - 「不纳入」和「没填写」都归零 → 一并消失；合计行保留。
5. **顺手修掉一个隐藏 bug**：原来实时预览和提交各写一套参数（预览应用了材料库取价、提交没有），材料价一变就会"预览一个价、保存另一个价"。现统一为 `calcInput`（useMemo），预览、保存、Excel 全用同一套。
6. `priceWarning` 文案改中性，避免"已设为不纳入"时误报误导。
7. API：`quotes.ts` zod schema 与 `web/api.ts` 类型都加 `off`；`paramsJson` 保存 `common.off` / `molds[].off` / `parts[].off`，供"按此版本重新报价"复现。
