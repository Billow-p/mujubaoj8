## 一、技术栈说明（与 PRD 的差异）

PRD 第 8 章建议 Python + FastAPI + MySQL + Docker。实际沿用现有 **Node.js + TypeScript + PostgreSQL + Nginx**，原因：

- 系统已上线运行，切换语言与数据库会中断业务；
- 计算引擎本来就是独立包（`@mqs/calc-engine`），同样满足 PRD 8.6「计算引擎独立，方便后续接 AI」；
- 服务器内存 1.6GB，Docker 编排会额外占用，原生部署更稳。

PRD 所有功能要求均在现有栈上实现，不因技术栈差异削减能力。

## 三、本次新增能力详解

### 1. 报价项中心（P3 + P7 + P8 + P9）

- 报价项字段：编码、名称、分类（材料费/模架/CNC/EDM/线切割/热流道/滑块/镶件/试模/表面处理/包装/运输/人工/管理费/利润/税费/自定义）、计入范围（模具/注塑/汇总）、单位、排序。
- 公式语法：数字、`+ - * / %`、括号、函数 `max/min/round/abs/floor/ceil/if`、比较 `> >= < <= == !=`、逻辑 `&& || !` 及 `and or not`、变量 `cavityCount` 或 `{cavityCount}`。
- 条件公式：`condition` 求值为真时才计入该报价项。
- 计算链：报价项可用编码引用其它报价项，按排序依次求值。
- 发布门禁：新建默认未启用 → 必须测试通过 → 才能启用；修改公式后自动停用并复位测试状态。
- 安全：仅白名单函数与白名单变量，不执行任意代码（已验证 `eval(1+1)` 被拦截）。

### 2. 参数中心（P4）

- 9 种参数类型：文本、整数、小数、金额、百分比、单选、多选、开关、日期。
- 编码规则：字母开头，仅字母数字下划线（非法编码已被拦截）。
- 参数值可直接被报价项公式引用；新建报价页按类型自动渲染输入控件并预填默认值。

### 3. 材料中心（P5 + P6）

- 预置 11 种塑料（ABS/PP/PC/PA/POM/PMMA/PVC/TPU/PBT/PPS/PE）与 5 种模具钢材（P20/718H/S136/NAK80/H13）。
- 支持自定义材料：编码、名称、分类、单位、密度、损耗率、单价、备注。
- 改价自动生成新价格版本，可查看历史版本列表（PRD 3.7）。
- 阶梯价数据结构与取价逻辑已实现（`priceRule=tiered` + `priceTiers`）。

### 4. 报价业务（P11–P14）

- 新建报价自动加载企业已启用报价项参与计算。
- 版本冻结：每个版本保存当时使用的报价项快照。
- 复制报价生成新单，原单不被改动。
- 客户库带报价统计（报价数、成交数、最近报价金额与时间），可下钻查看该客户全部历史报价。

### 5. 人工调整留痕（P12）

- 记录字段、系统计算值、调整值、原因、操作人、时间，同时写入操作日志。

### 测试中发现并修复的缺陷

1. **参数校验失败返回 500**：Zod 校验错误未做全局处理，前端只能看到「Internal Server Error」。已增加全局错误处理器，统一返回 400 + 中文提示。
2. **公式引擎缺少 AND / OR / NOT**：PRD 4.2 要求的逻辑运算原先不支持，已补齐并纳入测试。
3. **附加项与报价项未参与管理费加成**：已统一为成本基数参与加成，符合报价业务（成本项应产生利润）。

## 五、部署说明

部署脚本：`deploy/deploy-v1.0.sh`，执行内容：

1. 本地构建并打包；
2. 上传服务器；
3. 备份代码与数据库（`pg_dump` 到 `/opt/backups`）；
4. 解压覆盖（保留 `node_modules` 与 `.env`）；
5. `prisma generate` + `prisma db push`（只新增表与字段，不删除数据）；
6. 更新 Nginx 配置并重载、重启 API 服务；
7. 健康检查。

数据库变更均为新增：

- 新表：`Material`、`MaterialPrice`、`CustomParameter`、`QuoteTemplate`、`QuoteAdjustment`
- 新字段：`Customer.code`、`CustomFormula`（code / category / unit / condition / tested / lastTestAt / lastTestResult / version）
- 新关系：`Quote.adjustments`
