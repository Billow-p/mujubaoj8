# 客户分享页（客户查看报价单）

> 2026-09-10 · 补上「发邮件给客户」的最后一环

## 问题背景

此前 `POST /api/quotes/:id/send` 会生成分享链接 `https://ycwl.chat/share/<token>` 并随邮件发出，
但**前端从来没有 `/share/:token` 页面**，后端也没有对应的读取接口 —— 客户点开链接是 404。
也就是说「把报价单发给客户邮箱」这个功能实际上只做了一半。

## 现在的访问链路

```
业务员点「发送邮件」
   └─ 生成 token → 写 QuoteShare 表 → 邮件里带 https://ycwl.chat/share/<token>
                                        ↓
客户点链接 → nginx: /share/<token> 走 SPA fallback → 前端 SharePage
                                        ↓
        前端调 GET /api/share/<token>（免登录）→ 返回脱敏数据
                                        ↓
                      客户可点「确认接受此报价」
```

## 可见范围（刻意脱敏）

客户看得到：

- 公司抬头、报价单号、版本、报价日期、有效期
- 客户名、产品名、模具类型
- 产品规格（腔数、单件重量、注塑数量、首单数量等）
- **汇总**：模具费（不含税）、注塑费（不含税）+ 单件成本 × 数量、不含税合计、增值税、含税总价
- 商务条款（全部）
- 「确认接受此报价」按钮

客户看不到：

- 逐项费用明细（模芯钢材费、CNC 加工费…）
- **利润**（并入不含税合计，不单独出现）
- 内部工艺参数（钢材单价、模芯尺寸、模具重量、运输箱尺寸、原料单价、密度）

脱敏在后端完成（`shareSummary()` / `shareSpecs()` / `INTERNAL_PARAM` 白名单过滤），
**前端不参与脱敏** —— 即使有人直接抓 `/api/share/:token` 也拿不到成本构成。

## 几个刻意的设计

**版本快照**：客户看到的是「发送当时冻结的那一版」（按 `share.versionId` 取），
不是报价单的最新版本。业务员后续改价不会影响已经发出去的链接。

**过期即隐藏金额**：超过 `expiresAt` 后接口仍返回 200（给前端友好提示），
但 `summary` 置为 `null`、`specs` 清空，只保留报价单号和条款 —— 避免客户按过期价下单。

**访问留痕**：客户首次打开会写 `QuoteShare.accessedAt` 和一条 `QuoteLog(action='viewed')`，
业务员在报价单的「操作日志」里能看到客户是否已查看。

**确认即成交**：点确认后 `QuoteShare.confirmedAt` 写入、`Quote.status` 变为 `confirmed`。

## 老报价单的兼容

老报价单的 `paramsJson.parameters` 里没有 `group` 字段（这是后来才加的），
所以 `shareSpecs()` 做了兜底：没有 `group` 时用关键词黑名单
`INTERNAL_PARAM = /模芯|模具重|运输箱|钢材|原料单价|密度|运费单价|成本/` 排除内部参数。

实测老报价单正确显示：腔数、单件重量、注塑数量、首单数量、运输区域，
且不含模芯尺寸与钢材单价。

## nginx 注意点（容易踩）

原配置里有：

```nginx
location /share/ { proxy_pass http://mqs_api; ... }
```

这会把 `/share/<token>` 反代到后端，**挡住前端 SPA 路由** ——
届时后端没有这个 GET 路由，页面依然是 404。
本次已删除该 location，让 `/share/` 走 `try_files $uri $uri/ /index.html`；
后端接口统一挪到 `/api/share/<token>`，由已有的 `location /api/` 覆盖。

> 以后再加免登录页面时注意同样的问题：**页面路径不能被反代规则吃掉**。

## 测试覆盖（app/api/scripts/e2e-quote-excel.mjs 第 [N] 段）

25 项断言，含：

- 分享链接指向 `https://ycwl.chat/share/`（不是 IP）
- 免登录可读，金额与计算引擎一致（模具 59,747.5 / 注塑 13,090 / 含税 90,537.5）
- 不含税合计 = 模具 + 注塑 + **利润**（验证利润被并入而非单独暴露）
- 脱敏：不含 `lines`、不含 `"profit"`、不含「模芯钢材费」「CNC」「钢材单价」
- 规格含腔数与注塑数量、不含模芯尺寸
- 首次查看留痕（`QuoteLog.viewed` + `accessedAt`）
- 客户确认后报价单状态变 `confirmed`
- 过期后 `summary === null`，但报价单号与条款仍在
- 无效 token → 404
