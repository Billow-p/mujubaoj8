## 二、本地验收发现的 4 个真实缺陷（已修）

配置驱动（V1.0）改了数据结构：金额从 `calc.summary.*` 移到 `calc` 顶层
（`mold` / `injection` / `total` / `unitCost`）。但以下位置仍在读老字段，
导致金额显示为 0 —— **这些在纯 API 测试里测不出来，只有真实走前端才暴露**。

1. **报价单详情页金额全是 ¥0**
   卡片、客户与产品、模具与注塑明细都在读 `summary.moldIncVat`。
   已改为读 `calc.lines`，老报价单仍走原分支。

2. **客户库「最近报价金额」空白**
   `customers.ts` 四处统计读 `summary.grandTotalIncVat`，统一改走 `quoteTotal()`。

3. **发给客户的邮件金额为 0**（最严重）
   `send` 与 `resend-email` 两个接口组装邮件时读 `summary`，
   配置驱动下会向客户发出总价 ¥0 的报价邮件。

4. **报价列表 / 版本历史总价**
   `quotes.ts` 两处读老字段，已统一。

> 顺带建立了 `scripts/serve-local.mjs`：本地等价 Nginx（静态 + /api 反向代理），
> 以后改完前端可以先在本地跑真实产物验收再上服务器。
