# 配置中心 V1.1 — 设计说明与交付清单

用户目标：**不用写公式**。选一个计算方式、填几个数字，系统自己算。所有内容板块可增删改，数据存服务器。

## 一、核心设计：用「计算方式」取代「公式编辑」

模具报价的分项跑不出 8 种算法，全部做成下拉选项：

| 计算方式 | 用户要填的 | 系统生成的算式 |
|---|---|---|
| 固定金额 | 一个数 | `6000` |
| 数量 × 单价 | 数量选参数、填单价 | `腔数 * 2500` |
| 按模具尺寸算材料 | 长/宽/高选参数、密度、单价 | `模芯长 * 模芯宽 * 模芯高 / 1000 * 7.85 / 1000 * 钢材单价` |
| 工时 × 时薪 | 工时、时薪 | `96 * 400` |
| 重量 × 单价 | 重量选参数、单价、损耗 | `单件重量 * 单价 * ( 1 + 0.05 )` |
| 按比例算 | 基数选「模具小计/材料费合计」、百分比 | 基数 × 比例 |
| 报价时手填 | 不用填 | 报价时手动输入 |
| 高级：自己写公式 | 中文公式 | 逃生舱口，仅特殊算法需要 |

**公式在界面上不出现。** 每项下方显示的是中文读法（`模芯长 × 模芯宽 × 模芯高 → 换算重量 × 钢材单价 = ¥5,888`）。

## 二、管理费可手动调整

管理费不是硬编码，就是费用项列表里的普通一项：

- 默认「按比例算」，基数＝模具小计，比例 15%
- 想改成固定金额，把计算方式换成「固定金额」填个数即可
- 也可直接删掉，或改成任何其它计算方式

同理，利润率、税率在算价栏直接可改（存在模具类型上）。

## 三、一切皆可插拔

| 板块 | 可做的操作 |
|---|---|
| 模具类型 | 新增（可复制现有配置或从空白）、重命名、删除（保留至少一个）；一键初始化注塑/压铸/双色三套预置 |
| 产品数据 | 增删改名称、默认值、单位；改完右侧立刻重算 |
| 材料 | 增删改名称、单价、损耗率 |
| 商务条款 | 增删改文本、单独启停 |
| 费用项 | 增删改名称、分类、计算方式、计入范围（模具/注塑）、启停 |

预置的注塑/压铸/双色只是出厂模板，可以全部删掉自己建。

## 四、数据存储（按用户要求）

**当前阶段：服务器数据库（PostgreSQL）**，配置按企业隔离，多人可共用。

后续给客户部署时按客户要求选择：

- 云端：同一个后端，`DATABASE_URL` 指向客户自己的 PostgreSQL
- 单机：换成 SQLite 或本地 Embedded PostgreSQL，前端同一套代码

配置的导入/导出（JSON）作为便携备份与迁移手段保留。

## 五、代码变更

### 新增数据表

| 表 | 用途 |
|---|---|
| `MoldType` | 模具类型（含利润率、税率） |
| `QuoteItem` | 费用项（calcType + calcConfig + expression） |
| `BusinessTerm` | 商务条款（按类型隔离） |

`CustomParameter`、`Material` 增加 `moldTypeId` 字段，唯一约束改为 `[companyId, moldTypeId, code]`。

### 新增引擎函数（`packages/calc-engine/src/configured.ts`）

- `buildItemExpression(item)` — 计算方式 → 表达式
- `describeItem(item)` — 计算方式 → 中文读法
- `calculateConfigured(items, params, opts)` — 整单算价（含计算链、比例项、停用/手填处理）
- `friendlyCalcError(e)` — 技术报错 → 人话

现有 `calculateQuote`（原 11 项模具费模型）**未改动**，老报价单继续可读。

### 新增 API

```
GET    /api/mold-types               列出模具类型
POST   /api/mold-types               新建（可复制现有）
PATCH  /api/mold-types/:id           改名 / 排序 / 费率
DELETE /api/mold-types/:id           删除（级联其下配置）
POST   /api/mold-types/init-preset   一键初始化三套预置

GET    /api/config/:moldTypeId       读取整类配置
PUT    /api/config/:moldTypeId       整体保存（事务）
POST   /api/config/:moldTypeId/calc  试算
```

### 新增前端页面

`apps/web/src/pages/ConfigCenter.tsx`，路由 `/settings/config`，导航名称「配置中心」。

三栏布局：报价时填写（参数/材料/条款）→ 要收哪些费用（选计算方式填数字）→ 实时算价（可折叠）。

## 七、部署注意事项

1. 部署脚本执行 `prisma db push` 时需要 `--accept-data-loss`
   原因：`CustomParameter` / `Material` 的唯一约束由 `[companyId, code]` 改为 `[companyId, moldTypeId, code]`（允许注塑和压铸都有「腔数」参数）
   服务器上这两张表尚未部署（v1.0 未上线），**无历史数据，无丢失风险**
2. 部署脚本已内置 `pg_dump` 备份，先备份再变更
3. 新表全部为新增，不影响既有报价单数据

## 八、已知限制

| 项 | 说明 |
|---|---|
| 参数隔离粒度 | 参数/材料按模具类型隔离，跨类型不共享。如需通用参数，可在每个类型各建一份或后续增加「公共参数」概念 |
| 计算链 | 费用项之间可按名称互相引用（后面的项能引用前面的结果），暂不支持反向引用与循环检测 |
| 排序 | 费用项按列表顺序计算，暂不支持拖拽排序 |
| 新建报价页 | 尚未接入新配置（仍走原 11 项模具费模型），下一步工作 |
